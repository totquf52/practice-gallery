# PRD 세 줄 요약

## 언제 쓰나

- PRD.md 를 요약해 달라고 할 때
- 내 서비스가 무엇인지 짧게 알려 달라고 할 때

## 무엇을 받나

- 지금 연 폴더 맨 위에 있는 PRD.md

## 어떤 순서로 하나

1. PRD.md 를 읽는다
2. 누구를 위한 서비스인지, 넣을 기능이 무엇인지, 비목표(만들지 않기로 한 것)가 무엇인지 찾는다
3. 한 줄에 하나씩 적는다

## 무엇을 내놓나

번호를 붙인 세 줄로 적는다.

1. 누구를 위해 무엇을 하는 서비스인가
2. 넣을 기능
3. 만들지 않는 것 (비목표)

## 지킬 것

- PRD.md 에 없는 내용은 지어내지 않는다
