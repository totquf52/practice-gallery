# 넣으면 나온다

한 줄 : 실습 개수를 넣으면 → 실습마다 결과물 게시판이 바둑판 격자로 한 화면에 나온다

- 입력 : 실습 개수 하나를 숫자로 넣는다
- 처리 : 넣은 개수만큼 실습별 결과물 게시판을 번호 순으로 한 번에 만든다
- 출력 : 게시판 칸이 넣은 개수만큼(20을 넣으면 칸 20개) 가로세로로 깔려 한 화면에 다 보이고, 칸마다 실습 번호가 적혀 있고 칸을 누르면 그 게시판이 커진다
- 모양 : 만들어주는 도구 - 개수 하나를 넣으면 게시판 묶음이 나오기 때문
- 잘못 넣었을 때 : 개수를 비워 두고 만들기를 누르면 입력창을 빨간 테두리로 남기고 그 아래에 "실습 개수를 넣어 주세요"라고 한 줄 띄우며, 게시판은 만들지 않는다
