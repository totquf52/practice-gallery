# 내 아이디어 후보

## 후보 1 - 실습 결과물 게시판

- 무엇을 만드나 : 실습 번호를 넣으면 실습마다 결과물 게시판이 한 번에 생기는 화면
- 누가 겪는 문제인가 : 실습마다 결과물을 모을 노션 갤러리 페이지를 하나씩 따로 만드는 강사(나)
- 팀이 준 말 : (직접 적기 - 오픈채팅방 줄을 이름째 옮겨 적기)
- 만들 수 있나 : 번호를 넣으면 실습마다 탭이 생긴 표 파일을 만들고, 다 모인 표를 다시 넣으면 안 낸 사람 명단을 보여 주는 데까지는 만들 수 있다 - 학생이 각자 기기에서 올리는 건 이 과정에서 안 다룸

## 후보 2 - 유인물 뽑기

- 무엇을 만드나 : 수업에 쓸 문제를 골라 유인물 한 장으로 뽑아주는 도구
- 누가 겪는 문제인가 : 수업에 쓸 문제를 골라 유인물로 만드는 강사
- 팀이 준 말 : (직접 적기 - 오픈채팅방 줄을 이름째 옮겨 적기)
- 만들 수 있나 : 만들 수 있다 - 문제 목록 표 파일을 읽어 화면에서 고르고 한 장으로 저장하는 일이라 모두 과정 안에 있음 (문제가 이미 파일에 정리돼 있어야 함)

## 후보 3 - 슬라이드 장 링크

- 무엇을 만드나 : 강사가 장 번호를 넣으면 그 장이 바로 열리는 링크가 나와, 채팅에 붙이면 학생이 같은 장을 보는 화면
- 누가 겪는 문제인가 : 강사가 넘긴 장을 학생이 제 화면에서 따라가지 못하는 수업의 강사와 학생
- 팀이 준 말 : (직접 적기 - 오픈채팅방 줄을 이름째 옮겨 적기. 반응은 "학생 화면도 같이 넘어가는" 원래 모양에 달린 것)
- 만들 수 있나 : 만들 수 있다 - 화면을 인터넷 주소로 올리고 번호로 여는 링크를 만드는 건 과정 안에 있음. 저절로 같이 넘어가게 하는 건 이 과정에서 안 다룸

## 아직 못 버린 것

- 강사가 슬라이드를 넘기면 학생 화면도 같이 넘어가는 화면 - 여러 사람 화면을 실시간으로 맞추는 건 이 과정에서 안 다뤄서 장 번호 링크로 줄였지만, 팀에서 쓰겠다는 말이 나온 건 이 원래 모양이라 버리지 않고 남긴다
